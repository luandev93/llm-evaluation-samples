# LLM Evaluation Samples

This repository contains structured examples of side-by-side LLM response evaluation.

Each evaluation compares two candidate answers using explicit criteria such as accuracy, instruction following, relevance, completeness, clarity, unsupported claims, and overall quality.

The goal is to document clear, consistent, evidence-based evaluation decisions rather than simply selecting a preferred writing style.

## Structure

```text
llm-evaluation-samples/
├── README.md
├── templates/
│   └── side-by-side-evaluation.md
├── evaluations/
│   └── 001-instruction-following.md
└── rubric/
    └── evaluation-criteria.md
```

## Evaluation Approach

Each sample includes:

- The original prompt
- Response A
- Response B
- Scores by criterion
- A preferred response
- A specific written justification
- The main issue in the rejected response
- Confidence level
